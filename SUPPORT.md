# Support

Use GitHub Issues for reproducible bugs and feature proposals. Search existing
issues first and remove credentials, tokens, private repository names, payloads,
and personal data from logs or screenshots. This community project has no
guaranteed response time or service-level agreement.

For vulnerabilities, use the private process in `SECURITY.md`, not a public
issue. General GitHub, PostgreSQL, or deployment-provider support belongs with
the relevant upstream project.
